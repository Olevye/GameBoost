# GameBoost v1.1 - Global Gamepad Deadzone Manager

## Что это?

Это модуль для **GameBoost v1.1**, который добавляет продвинутую настройку мертвых зон геймпада с поддержкой трёх форм:
- **Circular** (Круговая) - стандартная радиальная обрезка
- **Square** (Квадратная) - независимая обработка осей X и Y
- **Cross** (Крестообразная) - усиленная чувствительность по осям, подавление диагоналей

## Как это работает?

### 1. Математика (C# класс `DeadzoneProcessor`)

Скрипт компилирует C# код прямо внутри PowerShell и использует его для расчёта векторов:
- Нормализует входные данные от геймпада (-32768...32767 → -1.0...1.0)
- Применяет выбранную форму мёртвой зоны
- Возвращает модифицированные значения

### 2. Глобальный перехват (DLL Proxy)

**Важно:** PowerShell не может напрямую создавать нативные DLL с экспортируемыми функциями. Для глобального перехвата в играх нужно:

1. Скопировать C# код из скрипта в проект Visual Studio (Class Library)
2. Добавить NuGet пакет `UnmanagedExports` (RGiesecke.DllExport)
3. Скомпилировать как `xinput1_3.dll`
4. Положить dll в папку с игрой
5. Переименовать оригинальный `xinput1_3.dll` игры в `xinput1_3_orig.dll`

Скрипт автоматически создаёт файл конфигурации `GameBoost_DeadzoneConfig.json` с вашими настройками.

## Запуск

```powershell
.\GameBoost_v1.1_Gamepad.ps1
```

## Управление в меню

- **Стрелки ВВЕРХ/ВНИЗ** - выбор пункта меню
- **Стрелки ВЛЕВО/ВПРАВО** - изменение значений (дляdeadzone)
- **ENTER** - применить изменения / переключить форму
- **ESC** - выход

## Требования

- Windows 10/11
- .NET Framework 4.7 или выше
- PowerShell 5.1+
- Для глобального перехвата: Visual Studio + UnmanagedExports (опционально)

## Структура кода

1. **DeadzoneCode** - C# классы с математикой векторов
2. **Generate-XInputProxyDLL** - функция создания конфига и инструкций
3. **Draw-StickVisualizer** - ASCII визуализация положения стика
4. **Show-GamepadMenu** - главное меню с навигацией стрелками

## Примечание

В текущей версии визуализация показывает симулированные данные (случайные колебания). Для реального отображения нужно подключить опрос контроллера через XInput в цикле меню.
