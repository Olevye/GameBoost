## 📖 О проекте

**GameBoost** — это мощный инструмент оптимизации Windows для геймеров, который автоматически настраивает приоритеты процессов, управляет звуковыми службами и применяет системные твики для максимальной производительности в играх.

Идеально подходит для:
- 💻 Слабых ПК и ноутбуков
- 🎮 Геймеров, желающих выжать максимум FPS
- 🔧 Энтузиастов, любящих тонкую настройку системы

---

## ✨ Возможности

### 🎯 Управление приоритетами процессов
- **Понижает приоритет** фоновых приложений (Discord, браузеры и др.), чтобы они не мешали играм
- **Повышает приоритет** популярных игр (Rocket League, CS:GO, CS2, Valorant и многие другие)

### 🔊 Защита звука
- Автоматический мониторинг звуковых служб
- Мгновенный перезапуск службы при сбое
- Опциональная поддержка перезапуска аудио-драйверов через `devcon.exe`

### ⚡ Оптимизация Windows 10/11
- Настройка схемы электропитания для максимальной производительности
- Оптимизация сетевых параметров
- Включение игрового режима и таймеров высокой точности
- Отключение ненужных фоновых процессов

## 🚀 Быстрый старт

### Установка и запуск

1. **Скачайте** репозиторий или скопируйте файлы в удобную папку
2. **Запустите от имени администратора**:
   - Дважды кликните на `GameBoost.bat`
   - Или правый клик → "Запуск от имени администратора"

3. **Готово!** Иконка появится в трее (рядом с часами)

### 🛑 Как остановить

- Правый клик по иконке в трее → **"Выход"**

---

## ⚙️ Настройка

Откройте файл [`GameBoost_config.ini`](./GameBoost_config.ini) в любом текстовом редакторе:

```ini
[Processes]
; Приложения с низким приоритетом (не мешают играм)
LowPriority = discord,chrome,firefox,spotify

; Игры с высоким приоритетом
HighPriority = rocketleague,csgo,cs2,valorant,fortnite

[Timing]
; Интервал проверки процессов (секунды)
ProcessCheckInterval = 3

; Интервал проверки звука (секунды)
AudioCheckInterval = 5

[Audio]
; Авто-восстановление звука
FixAudio = 1
RestartAudioService = 1

[System]
; Применять оптимизации Windows
ApplyOptimizations = 1
```

### 🔁 Применение изменений

После редактирования конфига:
- Правый клик по иконке в трее → **"Обновить конфиг"**
- Или перезапустите скрипт

## ⚠️ Важные замечания

- **Требуются права администратора** — для изменения приоритетов и управления службами
- **Антивирусы** могут ложно срабатывать — добавьте папку в исключения (скрипт полностью безопасен, можно проверить на [VirusTotal](https://www.virustotal.com))
- **Для продвинутого восстановления звука**:
  - Включите `RestartAudioEndpoint=1` в конфиге
  - Положите `devcon.exe` из Windows Driver Kit в папку со скриптом
